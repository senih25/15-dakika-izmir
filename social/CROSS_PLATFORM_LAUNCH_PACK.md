# Cross-Platform Launch Pack — İzmir Public Services Open Data

## Core identity
**Dataset:** Izmir Public Services Open Data Snapshot  
**Kaggle slug:** https://www.kaggle.com/datasets/senihbayankulu/izmir-public-services-open-data  
**Live public-service app:** https://15-dakika-izmir.vercel.app  
**Source & reproducibility:** https://github.com/senih25/15-dakika-izmir

Core proof points:
- 4,840 normalized public-service records in the current snapshot
- 5 layers: duty pharmacies, pharmacies, hospitals, street markets, emergency assembly areas
- CC BY 4.0 source attribution
- provenance + retrieval timestamps + coverage contract + machine-readable QA
- no personal user location in the dataset
- no neighborhood ranking or travel-time claim
