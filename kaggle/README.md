# İzmir Public Services — Open Data Snapshot

Five geospatial public-service layers normalized from official İzmir Metropolitan Municipality open-data sources.

**Start with:** `izmir_public_services_combined.csv`

Layers: duty pharmacies, pharmacies, hospitals, street markets and emergency assembly areas.

Evidence included: provenance, retrieval timestamps, coverage status, validation report and data dictionary.
